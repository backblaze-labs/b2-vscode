# GEMINI.md

This project keeps a single, tool-agnostic guide for AI assistants:
[`AGENTS.md`](AGENTS.md). Read it first.

carries no unique guidance. All shared knowledge lives in `AGENTS.md` and the
[`docs/`](docs/README.md) system of record so every assistant stays consistent.
